# Anam configuration

Maram's Cafe keeps the Anam API key on the server. The Admin page can update the API key and runtime identifiers without rebuilding the application.

Default identifiers:

- Avatar ID: `f01c2101-bdf3-4766-9f2a-ed07fa5fe139`
- Agent/share reference: `c38d14db-f0be-457a-90b0-87351d210591`
- Voice ID: `c48c4dd9-5050-11f1-9076-5e955d484d11`
- LLM ID: `a7cf662c-2ace-4de1-a21e-ef0fbf144bb7`

The Admin configuration API persists overrides in D1. The API key value is encrypted before storage.
